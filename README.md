# EcoSolar México

EcoSolar México es un proyecto académico sobre paneles solares
y cuidado del medio ambiente.

## Páginas del sitio

- Inicio
- Nosotros
- Servicios
- Impacto ambiental
- Cotización

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Google Fonts
- localStorage

## Funciones

- Navegación entre cinco páginas.
- Diseño adaptable a celular, tablet y computadora.
- Formulario con validación de datos.
- Guardado de un borrador en el navegador.

## Aclaración

El formulario es una demostración académica. Valida los datos,
pero no envía solicitudes a una empresa ni a un servidor.
